Check the address

This site is published from a GitHub project path, so every page address begins with /MLSec/. If you typed or edited the address manually:

  • keep the /MLSec/ segment;
  • match the capitalization of the file name;
  • remove a trailing extra path segment if the page is a section index.

For example, the lab index is /MLSec/labs/ and the first lab is /MLSec/labs/lab-01/.

Report a broken link

If you arrived here by following a link inside the course, that is a defect. Open an issue in the course repository with:

  • the address of the page that contains the broken link;
  • the link text or the address it points to;
  • what you expected to find.

Please do not include credentials or personal data in the report. For a security problem in the course materials, use coordinated disclosure rather than a public issue with an exploit.
