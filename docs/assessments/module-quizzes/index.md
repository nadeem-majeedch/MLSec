# Module Alternate Quizzes (QZ-00B to QZ-18B)

Each quiz here is an **alternate form** of the module's built-in knowledge check. It covers the same module and outcomes with different questions and numbers. It is not a harder version and not a replacement for the lab.

| Field | Value |
|---|---|
| Items | 8 per quiz |
| Points | 12 per quiz |
| Time guide | 20 minutes |
| Pass | 10/12 |
| Attempts | Unlimited; wait at least one day between attempts |
| Answer keys | Separate files under `assessments/answer-keys/module-quizzes/`, not linked from this site |

## When to use Quiz B

- **Second attempt.** You completed Quiz A, reviewed the missed lessons, and want a clean retest that is not the same paper.
- **Spaced review.** Three to four weeks after the module, use Quiz B to check retention.
- **Quiz A was seen early.** If you read the Quiz A answers while skimming the module, Quiz B is the uncontaminated check.

Do not use Quiz B to skip the lab. A quiz measures recognition and reasoning on paper; the lab measures whether you can produce the artifact.

## How to score and review

1. Attempt all eight items without notes.
2. Score with the key. Items 1–5 are 1 point, items 6–7 are 2 points, and item 8 is 3 points.
3. For written items, compare against the **required elements**, not the exact wording.
4. Record the score, the missed item numbers, and the lesson section to revisit.
5. Reread only the missed sections, then retake after at least one day.

| Score | Interpretation |
|---:|---|
| 12 | Strong. Move on and schedule a spaced review. |
| 10–11 | Pass. Review the missed item's lesson before the next module. |
| 8–9 | Not yet. Reread the module and redo the lab's interpretation questions. |
| Below 8 | Reread the lessons and rerun the lab before retaking. |

The key explains why each distractor is wrong. A retake that does not review those explanations is recognition practice, not review.
