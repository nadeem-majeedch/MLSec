# Level Checks (LC-1 to LC-5)

A level check tests the knowledge behind a level after you finish its modules and labs. It is cumulative within the level, not a substitute for the labs, and not a gate that unlocks content. It tells you whether the level's concepts are still available when the lessons are closed.

| Field | Value |
|---|---|
| Items | 10 per check |
| Points | 20 per check |
| Time guide | 30–40 minutes |
| Pass | 16/20 |
| Attempts | Unlimited; review before retaking |
| Answer keys | Separate files under `assessments/answer-keys/level-checks/`, not linked from this site |

## Structure

Each check follows the same shape:

- **Items 1–6, 1 point each.** Four multiple-choice and two true/false items on recall and one-step application.
- **Items 7–8, 2 points each.** Short written items that require a comparison, a correction, or a distinction.
- **Items 9–10, 5 points each.** Bounded scenarios that require analysis, design, or judgment. Answer with headings so the key can be compared element by element.

Every check mixes Bloom levels 1–5. The scenario items carry half the points because the level's outcome is judgment, not recall.

## How to interpret a level check

| Score | Interpretation | Action |
|---:|---|---|
| 18–20 | Strong | Move to the next level; schedule a spaced review. |
| 16–17 | Pass | Review the missed item and the linked lab. |
| 12–15 | Not yet | Reread the named lessons and repeat the level's labs before retaking. |
| Below 12 | Not yet | Repeat the level's labs and rebuild the core metrics before retaking. |

A pass without the level's lab artifacts is a paper result. The labs and projects remain the primary evidence for the course outcomes.

## Reviewing a missed item

1. Read the key's explanation of the keyed answer **and** of each distractor.
2. For a written item, list the required elements you omitted.
3. Revisit the lesson or lab section named by the item tag.
4. Retake after at least one day, using the same check or the module quizzes for the weak modules.

The tags on each key entry (`Mxx · LO-xx · Bloom n · Dn`) tell you which module to revisit and how deep the item was meant to go.
